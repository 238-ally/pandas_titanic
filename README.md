数据读取:

数据输入:
pd.to_文件类型("文件名称")

数据获取:
变量名.head(n):展示前n行数据,默认是5行
变量名.tail(n):展示倒数n行数据
变量名.shape:描述整个表格的列数,行数
变量名["列名"].操作方法():mean是取平均值,info看行数列名类型缺失值,value_counts

遇到的问题:
1:输出数据时没有12列中间是....:正常现象
解决方法:pd.set_option("dispaly.max_columns",None)
pd.set_option("display.width",200)
2:运行代码遇到报错:
解决办法:先直接看最后一行是什么类型的错误,然后往上找这个错误的行数
